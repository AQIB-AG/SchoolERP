# SchoolERP — Backend

Express API server for the SchoolManager landing page.

## Endpoints

| Method | Route           | Description              |
| ------ | --------------- | ------------------------ |
| GET    | `/api/health`   | Health check             |
| POST   | `/api/contact`  | Submit contact form      |
| GET    | `/api/contact`  | API status message       |

## Run

```bash
npm install
npm run dev
```

Server starts at **http://localhost:4000**
